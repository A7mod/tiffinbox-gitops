# TiffinBox GitOps Platform
A production-style GitOps platform on a laptop, told through one fictional company:
TiffinBox, a fast-growing home-food delivery startup. Every stage starts with a business
pain and ends with a working fix.

| Stage | Pain | Status |
|---|---|---|
| 0 | Only Rohit can deploy | Done |
| 1 | Who changed prod? | Done |
| 2 | But it worked on staging | Next |
| 3 | Release day is scary | Planned |
| 4 | The IPL-final outage | Planned |
| 5 | Team 3 needs Kafka by Friday | Planned |
